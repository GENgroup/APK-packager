# gen-packager — универсальный упаковщик HTML → APK

## Что это
Один репозиторий, который собирает минимальное Android-приложение:
- открывает во весь экран (без адресной строки, без меню) HTML-файл,
  который лежит на телефоне в `Download/GEN/<имя файла>`;
- http-потоки играют (разрешён "нешифрованный" трафик — специально
  настроено, это была главная проблема готовых конвертеров);
- чёрный фон вместо пустого окна при переключении;
- иконка и название — свои для каждой сборки.

HTML **не** зашивается внутрь APK — его можно менять на телефоне
простым перезаписыванием файла, без пересборки и переустановки.

## Первая настройка (один раз)

1. Создайте новый пустой репозиторий на github.com (кнопка "New
   repository"). Имя — любое, например `gen-packager`. Публичный или
   приватный — не важно.
2. На странице пустого репозитория нажмите "uploading an existing
   file" (или "Add file → Upload files").
3. Перетащите ТУДА ВСЁ содержимое этой папки целиком (включая
   скрытую папку `.github` — она обязательно нужна, в ней лежит
   сценарий сборки).
4. Внизу страницы нажмите "Commit changes".

Иконка `input/icon.png` уже положена (та, что вы прислали —
`!GEN-tv`, 512×512) — для первой сборки ничего дополнительно
готовить не нужно.

## Как собрать APK (на каждый проект/приложение)

1. Если нужна другая иконка для другого проекта — замените файл
   `input/icon.png` в репозитории на новый (той же командой "Upload
   files", с тем же именем `icon.png`).
2. Откройте вкладку **Actions** в репозитории.
3. Слева выберите workflow **"Собрать APK"**.
4. Справа появится кнопка **"Run workflow"** — нажмите её.
5. Появится небольшая форма с двумя полями:
   - **app_name** — название приложения, например `!GEN-tv`
   - **target_filename** — имя HTML-файла, который приложение будет
     искать на телефоне, например `!GEN-tv.html`
6. Нажмите зелёную кнопку **"Run workflow"** ещё раз (уже в форме).
7. Подождите 3–7 минут, периодически обновляя страницу — появится
   жёлтый/зелёный/красный значок статуса сборки.
8. Когда значок станет зелёным — зайдите на вкладку **"Releases"**
   (справа на главной странице репозитория) — там будет готовый
   `.apk`-файл для скачивания прямо на телефон.

Если значок стал красным — сборка не удалась, это нормально для
первого раза с новым инструментом. Откройте упавший шаг (клик по
названию), скопируйте текст ошибки — разберём вместе.

## На телефоне (первый раз)

1. Скачайте `.apk` из Releases и файл `!GEN-tv.html` (или как вы его
   назвали) — оба должны попасть в `Download/GEN/` (эту подпапку
   нужно создать один раз в файловом менеджере телефона).
2. Откройте скачанный `.apk` — Android спросит разрешение
   "установить из неизвестного источника" (для этого самого apk-файла) — разрешите.
3. После установки откройте приложение — оно попросит разрешение на
   доступ ко всем файлам (это стандартное системное окно) — разрешите
   и вернитесь в приложение.
4. Дальше приложение само найдёт файл и покажет плеер.

Чтобы обновить HTML в будущем — просто скачивайте новую версию файла
с тем же именем в ту же папку, приложение трогать не нужно.
